# Inventory Management (Rust)

A terminal-based inventory management mini-project written in Rust. The program models items with a name, quantity, price, and stock status.

## Implemented concepts
- Item creation and status tracking
- Quantity updates and sales
- Price updates and item removal
- Item information display and search

## Run
Requires the Rust toolchain (Cargo).

```bash
cargo run
```

## Language
Rust
